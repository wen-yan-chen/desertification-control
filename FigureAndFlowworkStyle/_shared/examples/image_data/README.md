### 从自己的照片重画剖面

在共享包根目录运行以下命令。四个坐标按显示方向从左上角计数，单位为像素。脚本生成 PDF、PNG 和 CSV，换照片时连同坐标、署名一起替换。

```sh
python -m examples.image_data.line_profile examples/image_data/stair5.png out/stair_profile --line 8 99 186 99 --credit "Team 2511565 · Fig. 4 · Stair 5"
```

示例在 5 号踏面局部照片上取一条 178 像素长的水平线，含两端共 179 个采样点。CSV 记录沿线距离与最近像素的灰度。可以用同一布局展示有空间标定的高度、温度或应变场，届时应使用对应的测量矩阵和单位。
