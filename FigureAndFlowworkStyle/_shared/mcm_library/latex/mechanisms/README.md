# 按模型机制选示意图

原图出自 desertification-control。每张都带可编辑的 TikZ 和编译预览。下表列出换题时应替换的内容。

| 要解释的问题 | 预览和源码 | 换题时怎么改 |
|---|---|---|
| 两个过程更新频率不同，如何互相驱动？ | [双时钟预览](m1_two_clocks.png) · [源码](m1_two_clocks.tex) | 改内外圈的时间单位、快慢状态和两条交接箭头。例如年初用设备状态设定每日负荷，年末把累计磨损传回年度更新式。同步修改右侧两条更新式和箭头编号。 |
| 存量守恒时，损失在哪里发生？ | [水桶预览](m1_bucket.png) · [源码](m1_bucket.tex) | 替换容器中的状态、入库前损失、实际入流、出流与溢流。让物理上限与触发运行规则的阈值各占一条线。改电池题时可用荷电量、充电损耗、用电量和放电保护线。 |
| 同一年为什么会执行不同的维护规则？ | [批次时间轴预览](m2_cohort_idea.png) · [源码](m2_cohort_idea.tex) | 左侧定义一个批次从启用到成熟的规则。右侧用同样的颜色表示同龄阶段，按投产年错列。选一个有不同龄批次同时运行的年份画竖线，解释当年各批采用哪条规则。 |
| 一次状态变化怎样对应到矩阵元素？ | [网格与矩阵预览](m3_matrix_discrete.png) · [源码](m3_matrix_discrete.tex) | 左侧选一个出发格，标出可能到达的位置。右侧在同一行用相同颜色定位对应列。原例的吸收态记录首次越线，若模型允许普通状态返回，按真实转移规则改写最后一行。此图为论文仓库中的备选图。 |

在本目录运行 `pdflatex -halt-on-error m1_two_clocks.tex` 即可重绘双时钟。其余三图使用各自的文件名。将示例另存到新项目时，把 [paper_palette.tex](paper_palette.tex) 与源文件放在同一目录。
