## 每轮如何推进

1. **用题面定图。** 写下图要支持的一句判断，选一张最接近的成图和相邻竞赛样例；把当届结果的列、连接键、单位、阈值和缺失规则写进项目适配脚本。先复用整图，再复用部件；调整图优先缩短说明、拆分面板或换图型。
2. **用一张图试版。** 先跑真实数据的一张，通过 `save_paper` 看字号和出界，打开实际 PNG/PDF，在 LaTeX 中按最终比例看一遍。相近方案应有可区分的线型/标记；同指标比较共用量程。坐标阈值、零与缺失、截断、区间定义要在图中或图注可查。
3. **复核论文证据。** 从结果表随机抽一个普通值，再抽极值、星标或阈值；逐一核对单位转换及图与正文是否一致。打印尺寸检查图例是否盖住数据、标注是否盖住点线、箭头是否连接准确、轴标签是否被裁切；用灰阶再看一遍。地图核对投影、底图来源与比例尺位置。示意与估计范围写进图注。
4. **晋升可复用成果。** 把项目读取、清洗和决策逻辑留在项目；抽取能接受另一份数据的通用函数。先对一份完整和一份不规则输入（例如漏目标或近重合曲线）核对，再回放涉及的旧基准。改公共 API 时记录兼容性，更新 [能力清单](mcm_style/CAPABILITY.md)、[选图目录](mcm_library/CATALOG.md)、版本号及一条最短调用示例。
5. **留下交接证据。** 在当次项目保存下面的记录和参考成图路径。公共包只收通用代码、调用说明及可复跑的校验，训练数据和按次成图留在项目或输出目录。

```text
图号 / 正文要支持的一句话：
参考成图和 O 奖论文图号／页码：
复用接口 / 公共包版本：
冻结输入、连接键、变化的单位：
抽查的数值 / 预览和最终输出路径：
人工复核（版宽、标签、图例、灰阶、图注）：

```
