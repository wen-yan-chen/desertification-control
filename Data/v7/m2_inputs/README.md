# M2 情景输入与证据登记（2026-11-11）

`scenario.json` 是可复算的演示规划实例，**不是于田县批准实施方案**。题面要求给定总预算及规划期，但未给预算、权重、供水、单价或劳力的数值；以下取值没有冒充题面硬约束。现有数据足以运行条件情景优化，不足以确定现场最优方案，`formal_model_ready=false`。

## 全参数登记

金额统一 CNY，不变价格情景；总预算是**全期未贴现总支出**，不扣光伏收入。全部单价按含人工的综合包价假设，劳动日用于产能约束，不再追加工资。
