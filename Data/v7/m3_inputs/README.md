# M3 数据、参数与证据边界（2026-11-13）

M3 从仓库最终 M2 建设计划结束时继续运行，不重做 M1/M2。`scenario.json` 为**未校准灾害情景**，`formal_model_ready=false`。

## 真实输入与接口

- 当前 M1 的 `adopted_parameters`、逐月气候态、储水映射，来自 `Results/v7/model1/`；不恢复已删除的风损伤系数 k。
- M2 第15年末3个批次：100 ha（V约17.114%、M约14.265 mm）、50 ha（23.446%、20.106 mm）、150 ha（16.903%、14.492 mm）。延续末年300/600/300 mm年申请水量，不把初态重置为K。
- M2旧结果保存的r、d与当前M1有约1e-8的计算差，旧k=0和η=1已经从M1接口删除。运行时逐批重放所有M2年份，若V/M差超过1e-5立即停止；保存实际误差，不修改M2数表或绘图。
- 风速变化对需水量的影响调用当前 `v7_m1_wind.wind_demand_factors`，按历史月气象重算Penman–Monteith比值，再乘M1气候态。数据来自该函数既有的POWER历史月表与已审计面板，作为响应比值，不替换M1气象来源。
- [FAO-56 第2章](https://www.fao.org/4/x0490e/x0490e06.htm)支持风速进入参考蒸散的物理形式；**不支持下表中的未来风速趋势或本地灾害损失率**。文献库 EN15 风沙损伤实验仅支持损伤机制，不能把风洞幼苗生理指标当作整批林带覆盖损失。

## 全参数登记

| 字段 | 基准 | 解释与证据类别 |
|---|---|---|
| `scenario_id`,`formal_model_ready` | post_m2_resilience_20261113；false | 版本和证据状态 |
| `horizon_years` | 50年 | M2完工后的评估期，不是题给固定年限；第1年为项目第16年，非公历2027年 |
| `paths`,`sensitivity_paths`,`seed` | 6000；3000；20261113 | 基准/平稳对照与其余情景的独立路径数、随机种子；统计误差不含参数/模型误差 |
| `failure_cover_fraction_K` | 0.30 | 年度观测V<0.30K即首次退化，约11.423个百分点覆盖代理；**不是30%绝对覆盖，也不是M2防护阈值或当地标准**。另算0.20、0.40 |
| `project_failed_area_fraction` | 0.50 | 同一年至少50%的治理面积低于各自阈值，判为项目首次触发事件；不是平均覆盖下降50% |
| `storm_rate_per_year` | 0.25次/年 | 泊松频率假设；允许一年多次，不以月均风速推断灾害次数 |
| `storm_loss_low`,`storm_loss_high` | 0.10、0.50 | 单事件覆盖比例损失均匀分布；假设而非本地观测。风沙事件合并表达沙尘暴、风蚀损伤和沙埋，避免三次重复计损 |
| `drought_probability` | 0.12/年 | 干旱年份伯努利概率假设；年度间不设持续相关，不代表SPEI实测频率 |
| `drought_probability_increment` | 每年+0.002 | 情景趋势；50年内概率从0.12到0.218。输入越界报错，不自动截断 |
| `drought_rain_multiplier` | 0.40 | 旱年有效降雨输入同比例减少；非植被直接减损 |
| `drought_et_multiplier` | 1.15 | 旱年温度加权ET0需求放大假设，不声称来自温度预报 |
| `drought_supply_multiplier` | 0.70 | 旱年外部供水年/月能力同时降至70%，之后按月配给 |
| `storm_rate_drought_multiplier` | 1.50 | 旱年风沙事件强度率提高50%，是假设关联，不是相关系数或已估计因果效应 |
| `wind_log_trend_per_year` | +0.005 | 风速基线乘exp(0.005t)，压力测试；不外推为塔克拉玛干确定变风趋势 |
| `rain_log_trend_per_year` | −0.005 | 降雨乘exp(−0.005t)，与蒸散共同改变水热湿润背景；不是CMIP/SSP预测 |
| `storm_rate_log_trend_per_year` | +0.01 | 风沙灾害强度率乘exp(0.01t)，独立声明的情景假设，不由平均风速机械推出 |
| `irrigation_multiplier` | 1.0 | M2末年申请水量倍数；实际取水仍受年/月上限约束，另算0、0.8、1.2 |
| `shock_order` | end | 基准先水分/生长更新、年末风沙冲击；start作对照。年初冲击也只在完整年末检查退化，未解析年内瞬时越界 |
| `shared_storms` | true | 所有批次同一年度承受共同风沙事件/损失，旱年也共同；独立风沙批次作关联敏感性 |
| `markov_grids` | (81,11,24)、(161,21,48)、(321,41,96) | 覆盖网格、储水网格、正事件保留率分位节点；另用(161,21,96)隔离状态网格与冲击积分误差 |
| `poisson_tail_tolerance` | 1e-12 | 转移核仅把极小泊松尾质量置于零保留率，MC直接抽完整Poisson，不截断；网格/分位压缩误差另核验 |

所有气候趋势从完工后的第一个评估年t=0开始施加。长周期由重复月气候态加趋势/随机旱年构成，没有声称取得逐年未来天气。

## 供水与成本边界

月供水优先保留M2已建PV的清洗申请，其余按生态申请比例配给，再检查总年限额；旱年缩减同一组上限。PV清洗也会在供水不足时缩减。所有控制均以m³计，1 mm×1 ha=10 m³。

后期假定能够继续养护与供水，没有新建、主动补植、灾后修复优化，也没有重新求M2。未来50年PV替换/融资和养护资金尚未核价，清洗预留只是持续服务的假设，不是光伏设备寿命或发电收入预测。M3输出长期植被状态、覆盖面积积分和退化风险，不编造未来现金收益。

M1背景r、d来自区域年度数据，无法与历史灾害损失完全分离；额外灾害项是压力扰动，仍可能与背景衰亡存在未识别重叠。这一限制需要新灾害清单及灾前/灾后遥感或实地数据消除，不能靠优化/模拟自行解决。
