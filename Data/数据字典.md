# 数据字典（Data Dictionary）

> 真实数据版本。所有 CSV 均为 **UTF-8 with BOM**（Excel 双击不乱码）。
> 单位约定：风速 m/s；降水 mm；气温 ℃；土壤含水率 %（体积含水率，m³/m³ × 100）；植被覆盖度 %；NDVI 无量纲；输沙率 t·km⁻²·月⁻¹；输沙势 无量纲（VU）。

---

## 一、`raw/` 原始数据（抓取后未清洗）

### 1. `01_站点月尺度面板_real_raw.csv`（960 行 × 18 列）

由 `01b_fetch_ndvi.py` + `01_fetch_real_data.py` 从 ERA5-Land（经 Open-Meteo）与 MODIS MOD13Q1（经 ORNL DAAC）抓取并组装。

| 字段 | 类型 | 单位 | 来源 | 说明 |
| --- | --- | --- | --- | --- |
| 月份 | 文本 | — | 生成 | `YYYY-MM`，2015-01—2024-12 |
| 站点 / 站代码 | 文本 | — | 站点表 | 8 站：塔中 TZ、肖塘 XT、且末 QM、民丰 MF、若羌 RQ、库尔勒 KEL、尉犁 YL、阿拉尔 ALE |
| 经度 / 纬度 | 数值 | ° | 站点表 | 站点坐标（ERA5-Land 就近取格点） |
| 地表类型 | 文本 | — | 站点表 | 流动沙丘 / 半固定沙地 / 戈壁 / 绿洲边缘 等 6 类 |
| 风速 | 数值 | m/s | ERA5-Land | 日 `wind_speed_10m_mean` 的月平均（原始 km/h，已 ÷3.6） |
| 风速日最大_月均 | 数值 | m/s | ERA5-Land | 日 `wind_speed_10m_max` 的月平均，用于输沙计算 |
| 降水 | 数值 | mm | ERA5-Land | 日 `precipitation_sum` 月累加 |
| 气温 | 数值 | ℃ | ERA5-Land | 日 `temperature_2m_mean` 月平均 |
| 土壤含水率_0_7cm | 数值 | % | ERA5-Land | 0—7 cm 体积含水率月平均 × 100 |
| 土壤含水率_0_100cm | 数值 | % | ERA5-Land | 0—100 cm 体积含水率月平均 × 100 |
| NDVI | 数值 | — | MODIS MOD13Q1 | 250 m、16 天合成；月内最大值合成（MVC）；填充值 −3000 已剔除 |
| 输沙率 | 数值 | t·km⁻²·月⁻¹ | 派生 | Lettau & Lettau (1978) 公式由日最大风速计算，经站级系数标定到文献年量级 |
| 输沙势 | 数值 | 无量纲 | 派生 | Fryberger (1979) DP = Σu²(u−u_t)t |
| 样本天数 | 整数 | 天 | 生成 | 该月实际天数（28—31），用于识别短月效应 |
| 植被覆盖度 | 数值 | % | 派生 | 像元二分模型，固定端元 NDVI_soil=0.05、NDVI_veg=0.85 |
| 端元方案 | 文本 | — | 派生 | 本版统一为“固定端元” |

### 2. `00_数据源清单.json`

记录每个数据集的名称、URL、引用、变量、单位、覆盖期、访问时间与调用结果（行数、缺失数），用于论文“数据来源”一节溯源。

### 3. `00_站点信息.csv`（8 行）

站点坐标、地表类型，以及接口返回的**实际取用格点**坐标与海拔（用于评估空间代表性误差）。

### 4. `01_文献参数锚点_raw.csv`（16 行）

从 16 篇核心文献提取的参数/结论锚点（真实表述），用于标定与论文引用；不参与数值清洗。

## 二、`processed/` 处理后数据

### 1. `02_panel_clean.csv`（960 × 20）—— 主分析表

清洗、截尾、插补、对齐后的完整面板（8 站 × 120 月，无缺失、无重复）。

| 字段 | 单位 | 说明 |
| --- | --- | --- |
| 站代码 / 站点 / 月份_str | — | 主键 |
| year / month / month_index | 年 / 月 / 月序号 | month_index = (year−2015)×12 + month − 1 |
| 地表类型 | — | 6 类中文类别 |
| 经度 / 纬度 | ° | 站点坐标 |
| 风速 / 风速日最大 | m/s | 已通过物理阈值与三准则异常检测 |
| 降水 / 气温 | mm / ℃ | 同上 |
| 土壤含水率 / 土壤含水率_0_100cm | % | 表层与剖面 |
| NDVI | — | 遥感指数（保留供反演与敏感性分析） |
| 植被覆盖度 | % | 像元二分反演 |
| 输沙率 / 输沙势 | t·km⁻²·月⁻¹ / — | 派生量 |
| log输沙率 | — | ln(1+Q)，建模目标 |

### 2. `03_features.csv`（960 × 20）

11 个建模特征 + 11 个稳健标准化值（`z_*`）：风速、降水、气温、土壤含水率、植被覆盖度、干燥度、月份_sin、覆盖度年变化、治理年限、风速_lag1、风速_lag3。

### 3. `04_train.csv` / `05_test.csv`

- 训练：2015-01—2022-12，**768 行**；测试：2023-01—2024-12，**192 行**
- 按时间切分，未随机打乱；截尾分位数与标准化参数仅由训练期估计

### 4. `06_scaler_params.csv`（11 行）

每个特征的中位数（center）与 IQR（scale）。**新数据必须用这套参数变换，不可重新拟合。**

### 5. `07_交叉验证_POWER.csv`（3 行）

ERA5-Land 与 NASA POWER（MERRA-2）的逐月对比：n、均值、偏差、RMSE、R²。用于量化再分析数据的代表性误差。

## 四、30 秒完整性自检

```python
import pandas as pd
d = pd.read_csv("Data/processed/02_panel_clean.csv", encoding="utf-8-sig")
print(d.shape)                                   # 期望 (960, 20)
print(d.isna().sum().sum())                      # 期望 0
print(d.groupby("站代码").size().unique())        # 期望 [120]
print(d[["风速", "输沙率", "植被覆盖度"]].describe())
```

三项不全过，说明面板对齐或插补失败：先查 `stats.json` 的 `panel_fill.still_missing`。
