# 原始数据的证据等级

- `nasa_power_verified/`：本轮从NASA官方API取得的原响应、清单、单位与月表。可核验下载来源；是格点产品，不是当地仪器测量。
- `01_站点月尺度面板_real_raw.csv`：保留旧版960行混合来源面板供审计。名字中的`real`不能为整表背书。输沙率含无逐站证据的人为目标缩放；输沙势量纲及固定端元FVC有问题，禁止当作校准真值。
- `00_站点信息.csv`：8个命名坐标点，不等于正式研究区或经确认的8个观测站；地表类型标签需GIS核验。
- `00_数据源清单.json`：旧生成流程的来源宣称，保持原样供追溯，部分已被审计纠正；当前不得用它证明整表源于ERA5-Land。
- `01_文献参数锚点_raw.csv`：A01--A16统一状态为 **pending_source_verification**。原文题名/页码、尺度和用途仍须逐项核验；不得自动进入正式参数集。数值保留原样不代表认可。
- `local_project_evidence/`：官方网页的核验清单及参数登记；工程配置、成本节约和总成本严格区分，不能据新闻替代可研/批复。
