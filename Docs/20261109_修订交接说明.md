## 一、必须说清的三件事

1. **风蚀在月尺度不可识别**：任务一的风蚀项系数在 8 个站点全部被标定到边界 0。
   这不是“风蚀不重要”，而是“用月均风速构造的侵蚀指数解释不了月际覆盖度变化”。
   风蚀效应更可能发生在事件尺度或通过多年累积体现，需要事件级或年际数据才能识别。
   因此任务二里的“减蚀效益”纯粹是情景设定，不能当作已标定的机制。

2. **长期预测没有技能**：一步预测 7/8 站为正技能（测试期 R² 中位 0.414），
   但推进到 12 个月时，RMSE 中位 8.35 已大于持续性基线的 4.30。
   所以报告里任务二、任务三的曲线**都是情景推演，不是预测**；
   我们不再使用“15 年失效概率 84%”“2050 年 6.7%”这类单点结论。

3. **代表区段边界仍未划定**：8 个坐标点是区域点位，不是等距锁边带样带；
   塔中是腹地背景点，肖塘与塔中直线距离约 36 km。
   报告中已改称“区域点位”，不再声称“各站均代表边缘”。

## 二、其他实质改动

| 方面 | 之前的做法（错） | 现在的做法 |
|---|---|---|
| 气象数据 | Open-Meteo 默认模型，未指定产品 | 统一 NASA POWER 月度产品（7 参数），逐请求记录 URL 与 SHA256 |
| 输沙率 | 逐站强行贴到 400—3200 的目标 | 取消目标；用无量纲侵蚀指数 E = q / q̄，不宣称 t·km⁻²·a⁻¹ |
| 水分状态 | 自造水桶，体积含水率与 mm 混用 | 直接用 POWER 根区湿度 GWETROOT（0—1），训练期分位归一 |
| 参考蒸散 | 温度线性代理却称 Hargreaves | 按 Hargreaves 原式计算，天文辐射 Ra 解析求得 |
| NDVI 质量控制 | 只剔填充值 | 补 QA 抽样评估：TZ/XT 的 QA>1 占 0.87%，月最大合成月均差 0.00 pp、最大 0.55 pp；QM 的 QA>1 达 15.2%。全序列另加“相对气候态 |z|>3”筛查 |
| 训练/测试 | 全 120 个月一起拟合 | 训练 2015—2022 标定，测试 2023—2024 评估；插补、归一、共线筛选只用训练期 |
| 任务二 | 手设 V(A) 响应函数，运维单价少乘 1000 | 稳态覆盖度由任务一方程解析求解；单位统一为 万元/hm² |
| 任务三 | 月滞后系数当年恢复、λ 硬编码 0.35、同年多次事件被合并 | λ 由实测 95% 超额频率估计（0.625 次/年）；恢复时间按“回到冲击前 90%”定义并右删失 |
| 长期情景 | 趋势项没进计算，2026+25 写成 2050 | 气温 +0.03 ℃/a、风速 +0.2%/a 显式进入 f(T) 与 E_t |
| 报告体例 | 含时间安排、验收指标（R²≥0.45、收益高 1.5 倍） | 全部删除；新增“审计意见与本版处理对照表” |
