# M3 复核与实现（2026-11-13）

已从远程同步至 `ccbf1a2`。本轮完成M3代码、情景数表、验证和绘图交接；未改变M1/M2的代码、参数、数表、论文或图片。沿用最新M1“无直接风损伤项”的实现。M2当前定稿仍为线性覆盖积分，本轮不重新调整其目标或补算此前讨论的覆盖门槛。

## 不能照抄旧稿的地方

| 旧稿问题 | 更正 |
|---|---|
| 声称复合Poisson，转移核却用`1−λ`与`λ`只表示0/1次事件 | MC完整抽Poisson次数；核按所有次数加权，无灾概率exp(−λ)，λ允许大于1 |
| 将平均乘性保留率exp(−λE[U])写为小U近似，并据此断言全面不可识别 | 这是独立同分布标记下的精确均值；仅从均值无法分离λ和E[U]，完整分布可含更多信息 |
| 只有V的网格、初始统一设K、上界1.5K | 继承M2分批V/M末态；暂态网格为[ρK,K]×[0,C]，不丢储水记忆 |
| 行随机矩阵与列向量乘法方向混用 | 行分布p0，存活概率p0 Q0 Q1…Q(H−1) 1；吸收质量为补数 |
| 无条件求基本矩阵且把有限模拟均值当寿命 | 平稳子模型满足有限吸收时间时解线性系统；非平稳主结果报告右删失、RMST(H) |
| 令λ=0就要求概率0、期望时间无穷 | 无风沙仍可能因停水/干旱退化；分别测试无灾持续供水与停水 |
| 拟将旧k的上界乘2/5作为灾年损伤 | 最终M1已删除该项；本轮不恢复k，不把不确定上界当实测灾害系数 |
| 风沙削减与外生W趋势忽略供水和各类灾害联系 | 风沙冲击合并风蚀/沙埋；旱年改变降雨、ET0g、年/月供水能力，并可提高风沙事件率 |
| “吸收”易误写为不可恢复的生物状态 | 只有首次越界记忆吸收；物理V/M继续更新，当前低覆盖与曾退化分别输出 |

更正正文位于 `Reports/model_v7/m3_correction.tex`，由模型总报告在原M3章节位置引入。M1/M2原公式未改。旧检验报告 `model_validation_m1m2` 是2026-11-12历史状态，其M3“尚无实现”不再代表当前进度。

## 初态和参数证据

M3从M2第15年末开始，向后50年。3批次100/50/150 ha、年水量申请300/600/300 mm；实际V/M来自M2导出。当前M1与旧M2小数精度及元数据略有差异，逐批重放M2全部年份后最大V/M绝对差为 **2.824e−6**，在1e−5接口容差内；不重新覆盖队友定稿数据。

M1真实气候与参数继续使用，风速对蒸散的响应沿用M1既有Penman–Monteith比值函数。**灾害频率、损失幅度、干旱年概率、未来趋势和退化阈值尚无本地标定依据**，全部登记为情景；详见 [输入证据说明](../Data/v7/m3_inputs/README.md)。本轮没有把历史月风速、文献风洞实验或取水能力假设冒充事件记录、覆盖损失或未来预测。

基准包含共同旱年与共同风沙事件；将风沙磨蚀/沙埋作为一次事件的综合覆盖损失，不重复累加。同一年旱情条件下事件率乘1.5，仅为关联情景。年度之间暂不设旱情持续相关，仍是模型限制。

退化阈值为 **0.30K≈11.423%覆盖代理**，不是“30%实际覆盖”。项目事件是同一年至少50%的治理面积低于该阈值。首次越界可以在随后年份恢复，不能据首次越界概率说工程永久失效。

## 已实现与数值结果

- 主程序 `Code/v7_model3.py`：27组情景，基准/平稳参考各6000条路径，其余各3000条；每次50年，含风/雨趋势、干旱、风沙及关联；输出轨迹、效益积分、首达和资源账本。
- 核心 `Code/v7_m3_core.py`：向量化复现M1日子步水量守恒，外加逐月配给、完整复合Poisson、Wilson区间、二维平稳暂态链。
- `Code/v7_m3_grid_check.py`：额外交叉网格单独检验状态离散和冲击积分，避免同时加密后分不清误差来源。

**以下都是假设条件下的压力测试数值，不是对实际工程灾损的预测。**

| 基准非平稳结果 | 后10年 | 后30年 | 后50年 |
|---|---:|---:|---:|
| 项目曾触发退化面积标准概率 | 77.47% | 99.57% | 100%样本命中 |
| 该概率Wilson 95%区间 | 76.39%–78.51% | 99.37%–99.70% | 99.936%–100% |
| 当前低于阈值的期望面积 | 106.07 ha | 155.62 ha | 200.22 ha |
| 累计覆盖达成率积分均值 | 1168.68 | 3093.88 | 4761.89 有效ha·年 |

50年内项目受限平均首达时间约 **7.13年**；这既不是项目物理寿命，也不是精确无条件期望寿命。50 ha高补水批次的50年首达概率约98.9%、RMST约16.11年；其余批次RMST约7.13–7.18年。平稳二维参考的平均首达时间约7.85、21.75、7.78年，只对平稳无限期情景适用。

同样气候趋势但无随机灾害时，50年覆盖积分约7271.79；基准约为其65.5%。低频低损失情景（初始λ=0.1、E[U]=0.15）的项目50年首达概率约44.87%，表明结论强烈依赖尚未标定的灾害参数。不能把基准的高风险写成普遍现实结论。

月供水配给实际生效：提高20%申请水量不意味着可以突破能力上限。所有27组情景的水量均受同一M2年度/月度能力约束（旱年再按比例缩减）。后50年维护资金和PV更换寿命未估价，未输出超出证据的长期财政收益。

## 验证与适用范围

M3的9项测试包含：M1/M2接口、批量与原M1标量对照、水量单位和配给、完整Poisson矩、无灾停水反例、删失和Wilson边界、初始退化t=0、二维链方向与MC对照、非法概率趋势拒绝。

最终联合回归为 **28项通过**（M1 12项、M2 7项、M3 9项）。另对已导出的27情景、108个实体汇总及32400行条件月资源表核验：12项输入/源码哈希一致，年度/月度取水不超限，首达频数合计与路径数一致，删失及RMST可从频数重算，覆盖/储水/概率域合法。仓库文献及353处本地链接检查通过；修正了一处读题文档的旧相对链接。

主计算最大月水量闭合残差 **4.84e−13 mm**。最细网格的3批次×10/30/50年共9个概率对照，均位于MC 95%区间，最大绝对差1.055个百分点；这是数值/抽样一致性，不是实地准确率。中等网格有1点略超区间，未删除该结果。

保持96个冲击节点、加密V/M网格，最大概率差 **0.0381个百分点**；固定中等状态网格、48→96冲击节点，最大差 **0.2024个百分点**。均小于原设计1个百分点判据，但只能说明本组参数下的有限分辨率检查，不证明所有情景网格均已收敛。详见 `validation_summary.json`、`grid_validation.csv`。

长期路径分位带仅反映给定参数的随机灾害；概率Wilson区间仅反映MC误差。均未包含M1参数、初态、事件率、遥感代理和气候趋势不确定性。背景衰亡与新增灾害损失可能重叠，仍需事件前后观测分离。
