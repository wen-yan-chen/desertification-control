## 已确认的问题、修正和影响

| 问题 | 证据 | 本轮处理 |
|---|---|---|
| 只有代数供需比 W，没有水分状态方程 | 原 `v7_model1.py::water_factor` 每年仅由供应/需求求 W，不携带储水 | 增加有效储水 M 的年内收支；V 方程保留，W 由实际/潜在蒸腾比给出 |
| QA 过滤的是窗口中位质量，不是 NDVI 对应像元 | `v7_clean.py` 原先按 QA 中位数筛合成期，NDVI 均值包含坏像元 | 重取相同原始 MODIS，逐像元、日期、栅格严格对齐；0/1 才保留，覆盖不足则缺测 |
| 原 manifest 不能原样重放 MODIS | `v7_finalize_fetch.py` 把分块 `endDate` 写成 `startDate` | 修正生成器读取响应里的末日期；新增重放清单同时记录旧 URL、新 URL、两组哈希 |
| 风指数聚合顺序和数据口径错误 | 原代码将月产品 `WS10M_MAX` 当作“日最大值的月均”，再套非线性公式 | 从日值先算 `u² max(u−5,0)`，后取月平均，按站内训练期日均值归一 |
| Hargreaves 用月极端温差冒充平均日温差 | 旧 `T2M_MAX/MIN` 直接代入；NASA 明确区分极端参数与 `_AVG` | 当前 M1 不使用该 ET0，使用已有 Open-Meteo ET0；审计输入附真正的平均日最高/最低温供后续重算 |
| 全序列双向线性插值不等于无泄漏预测输入 | 旧预处理的 `interpolate(limit_direction='both')` 可读未来月份 | M1 不使用插补 V；只用实际 QA 观测，训练/测试按目标年分离 |
| “自由拟合 r、d 与站点一致”不是识别证据 | 当 W=1,k=0，方程只含 `r−d` 与 `r/K`，自由 r,d,K 存在等价族 | 自由区段模型只拟合净增长率、平台、初值；删除以自由 r,d 一致证明机理的结论 |
| 区段 CON4 不是严格独立预测验证 | 旧分支 `270e468:Code/m1_build_dataset.py` 用后期 NDVI 选择 converted 像元，建植时间看未来 3 年 | 保留作回溯空间诊断，明确选择偏差；不再宣称“从未使用”或独立预测验证 |
| 水分曲线用全时期气象，温度和 ET0 混源 | 旧曲线取 2015—2025 均值，温度为 POWER、ET0 为 Open-Meteo | 情景气象仅用 2015—2022 于田/民丰同源 Open-Meteo 月气候态；与测试成绩分开 |
| Open-Meteo 具体模式声明过强 | 原请求未指定 `models` | 使用“Open-Meteo 历史归档”称谓；不声称固定纯 ERA5-Land |
| 遥感高分位不等于实测满覆盖 | 局地绿洲 NDVI 0.5827 只是选取的端元 | 保留端元换算作假设代理，配端元敏感性；不把曲线标签写成实测地面覆盖 |
| 半衰期用错时间模型 | 原年离散衰减 `Vnext=(1−d)V`，却写 `ln2/d` | 改为 `ln(1/2)/ln(1−d)`；它仅对应无水、无额外风损伤条件 |
| 200 年迭代未检查收敛 | 原 `steady` 直接返回最后一点 | 对 V 与 M 的周期不动点均检查残差，并由低、高两个初值核对；未收敛显式标记 |
| 旧曲线/报告与当前实现混用 | README 曾仍写“尚未求解”，旧图引用旧参数 | 更新导航；旧 PDF 加历史/更正提示；当前模型附录只规定公式、参数、约束 |

## 原始数据核验

- 重放 198 个生长季 MODIS 分块，**198 个字节 SHA256 全部与原清单一致**。每个分块的 A161—A305 覆盖该年 6—9 月的所有合成期。
- 重放 9 个 POWER 日响应；字节哈希与旧记录不同，旧新哈希都保留，不能冒称原始快照一致。
- 重放的未过滤 NDVI 月最大均值与旧面板最大绝对差为 `1.67e-16`，排除了换了一套植被观测的可能。
- M1 的 396 个生长季站月中 395 个有效，1 个缺测。非生长季的 792 个 V 值**按用途故意留空**，不是 66.7% 的观测质量缺失。
- 所有训练生长季月份通过 50% 有效像元门槛；另用 75% 门槛重算拟合。每年需至少 2 个有效月份，输出保留每年及预测对两端的观测数量。
- 原面板未覆盖，防止旧报告静默变化。当前唯一 M1 输入在 `Data/v7/m1_audited/`，旧 `processed/` 和旧预处理/消融脚本只作比较材料，不作为当前 M1 入口。

## 当前模型和证据等级

植被仍用年递推，`r,d` 在假设灌溉绿洲不受水限制的情况下合并标定，K 保留训练期 95% 分位乘 1.15 的规则。土壤有效储水 M 为高于凋萎点的水深（mm），年内随入水、蒸腾、排水变化；W 是年蒸腾满足率，**不是 M 的别名**。

储水方程结构参考 [FAO-56 第 8 章](https://www.fao.org/4/x0490e/x0490e0e.htm)。容量 75 mm、有效降水比例 0.25、净灌溉比例 0.75 等为明确情景假设，并非 FAO 给出的当地测量值。月气候态均匀分配至月内数值子步，不能冒称逐日实测天气。有效入水比例已经合并表土蒸发等损失，不再重复扣水。

雨水不再被无证据地设为零。基准下 0 灌溉仍有少量有效降水维持覆盖；零植被为吸收态，必须通过显式建植初值建立植被，水本身不凭空创造植株。

沿用既有于田—民丰南缘选窗为代表性研究对象，宽 1 km 作为研究情景；窗口不代表已验证的工程多边形。所有用水按 mm 或 m³/ha 输出，不伪造区段总工程用水。真实边界、地下水补给和工程可用水量仍待补充。

## 计算结果

| 指标 | 当前数值 | 解释 |
|---|---:|---|
| r | 0.5467/年 | 条件合并拟合；局部近似标准差 0.1737 |
| d | 0.1073/年 | 条件合并拟合；局部近似标准差 0.0328 |
| 训练/留出转移 | 49 / 21 | 目标年 ≤2022 / 2023—2025 |
| 训练 RMSE | 0.0516 | 单位 V/K |
| 留出 RMSE | 0.0635 | 单位 V/K |
| 持续性留出 RMSE | 0.0536 | **模型没有优于持续性** |
| 留出 R² | 0.463 | 相对总体均值，不能据此宣称胜过持续性 |
| 站点均值留出 RMSE | 0.0737 | 只使用训练期，包括 2022 年 |
| 300 mm/年情景稳态 V | 17.94 | 旧端元覆盖代理百分点；不是实测灌水响应 |
| 600 mm/年情景稳态 V | 24.14 | 同上 |
| 最大水量平衡残差 | 5.26e-13 mm | 本次 14 个情景的逐月收支 |

另给出从 2022 年出发连续递推 2023—2025 的结果，不与逐年使用真值起点的一步预测混为一谈。
300 次站点整簇 bootstrap 的 r 2.5%—97.5% 分位约为 0.335—1.168，d 为 0.077—0.202；只有 7 个簇，说明不确定性仍然很大。r 超过 1 的重采样参数不直接投入当前年步长水分场景；当前状态域约束会拒绝不安全组合。

## 尚未通过的证据门槛

1. 真实灌溉量—储水—覆盖同期数据缺失，水分子模型尚未现场标定。
2. 风损伤与实际输沙缺测，k、遮蔽率仅作情景，不能写成实证减蚀百分比。
3. 城镇/绿洲窗口不能直接代表全部锁边灌木带；CON4 诊断不弥补这一外推缺口。
4. 工程区段边界、可用水、工程/维护单价及劳动力约束尚需证据，不能声称全项目最优方案已经可执行。
5. 旧预处理文档中月极端温差、双向插值、SoilGrids 备用换算及旧消融仍有历史口径问题。当前 M1 绕开这些路径；旧脚本不是经本轮认证的全任务流水线，不应用于生产当前 M1 输入。

## 外部口径核对

- [NASA POWER 时间聚合文档](https://power.larc.nasa.gov/docs/methodology/data/processing/)：极值参数与日极值均值不同，不能在 ET0 公式中混用。
- [Open-Meteo 历史接口说明](https://open-meteo.com/en/docs/historical-weather-api)：若需一致的特定再分析模式，应显式选择模式；本项目原请求没有这样做。
- [FAO-56 土壤水分与胁迫](https://www.fao.org/4/x0490e/x0490e0e.htm)：水分容量应由土壤水力性质和根深定义；当前没有当地实测参数，采用的数值明确是情景。
