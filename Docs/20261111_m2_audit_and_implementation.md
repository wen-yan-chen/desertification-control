## 原方案问题及处理

| 问题 | 后果 | 本轮更正 |
|---|---|---|
| 只给新增面积算水，却给累计面积算稳态收益 | 老林无需补水、新植立即成熟，物理与成本账不一致 | 每个建植年份/策略分别追踪 M1 的 V、M，所有在役面积每年补水养护；年内收益按 V_start |
| 用任意线性 `Ks(I)` 替代 M1 | 与已完成的储水动态相矛盾 | 原样调用 `v7_m1_water.trajectory`，携带储水，不改 M1 结果 |
| 只有年预算 | 不能满足题目“给定总预算” | 全期未贴现支出≤总预算，同时各年支出≤年预算；收入不冲抵硬预算 |
| 光伏仅在新增年算收益，无真实资产账 | 漏资本费、后续运维与发电 | kW装机资产逐年保留，建造次年发电，包含衰减、运维、清洗水与劳动 |
| 光伏面积占比被当作投资结构 | 不能覆盖建设/运维/收益设施三类资金 | 三类支出逐年核算、比例由平衡等式决定；另外支持全期光伏资本占比边界 |
| 劳力只是新增面积的一条不完整约束，伪代码漏查 | 老林与光伏没有运维人力 | 显式年度人日投入=各项工程工时，受上限约束；含人工包价不再追加工资 |
| `Code/v7_ablation.py` 的历史 `task2_npv` 水量还有 `/1000` 错换算 | 历史试算严重少算水量 | 当前 M2 不调用该函数。旧消融文件保留作历史对照，在入口说明其不能作为 M2 求解器 |
| 仅累计面积作为 DP 状态且声称全局最优 | 无法区分林龄、水分、资产龄和剩余预算 | 有限 M1 轨迹库+混合整数模型；最优界仅适用于该网格/策略库 |
| 静态光伏占比阈值与一次性收益口径冲突 | 错误的立项结论 | 改为独立光伏收支平衡电价筛查，并要求全系统约束复核及机会成本比较 |

题目给定的决策类别、总预算约束、生态与经济权衡均保留。题面未给具体预算、权重、供水和单价，没有将自设数值写成题给值。模型文档不规定编程交付物。

## 数值方案与结果解释

15年基准实例：总预算8,000万元、年度上限1,200万元、用地1,200 ha、年取水150万m³及12个月分别限额、年劳动12,000人日。均为情景假设。生态治理面积50 ha一块、PV100 kW一块；18条逐龄年补水策略，临近终期重复路径自动去重。光伏和生态用地不重叠。

先最大化覆盖达成率面积时间积分 H，得到参考可行值 **2,097.03有效ha·年**，其求解上界约2,098.93。基准要求达到参考值60%，即 **1,258.22有效ha·年**；60%是演示政策选择，非题目权重或推荐政策。

在这组假设下：

| 指标 | 结果 |
|---|---:|
| 最终治理面积 | 300 ha（第1、2年各150 ha） |
| 最终光伏装机 | 9,500 kW（第1–4年依次1,200、1,100、3,700、3,500） |
| 实现生态积分 | 1,264.84有效ha·年 |
| 全期未贴现总支出 | 6,892.73万元 |
| 生态建设 / 运维补水 / PV建设总支出 | 1,575.00 / 2,467.73 / 2,850.00万元 |
| 净现成本（支出减光伏现金收入） | 2,535.00万元 |
| 基准目标值下界 / 相对间隙 | 2,529.94万元 / 0.1994% |
| 最大年度取水 / 最大年度劳动 | 105.019万m³ / 5,522人日 |

这些数值不是现场投资建议，也不是连续控制问题的全局最优。经济目标使用实际贴现率5%的情景，不计税、融资、终期残值与终期后养护义务；生态积分不货币化，不声称因果新增效益或减蚀吨数。

共导出 **29个求解记录**（含基准与前沿60%重复点），全部找到可行解，报告间隙均≤0.20%。基准面积网格改为25 ha时净现成本约2,529.50万元，变化约0.22%；数值接近但不能据此断言网格收敛。仅允许恒定补水时约2,703.57万元，说明灌溉策略库确实影响方案。所有敏感性保持基准绝对生态目标，避免改变任务难度后比较成本。

低电价0.15元/kWh、高PV资本费3,750元/kW时均选择零光伏；不能预先指定“光伏一定越多越好”。基准第一年新建独立PV的保本结算价约0.2526元/kWh，但不含资源机会成本，不能单凭该数值立项。生态初始覆盖1%与4%分别使净现成本变至约3,273.61和2,041.58万元，说明初始建植效果本身是重要证据缺口。
