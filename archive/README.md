# archive 归档说明

本目录集中存放**合成数据样张、风格实验与历史工作流**，用于团队学习制图与排版，**不是本题的研究结果或实测数据**。正式建模产物请放在 `Paper/`（论文）与 `Code/`、`Data/`、`Results/`（分析流水线）。

| 子目录 | 内容 | 数据性质 |
|---|---|---|
| `FigureStyleDemos/` | 前期两批共 35 个图表实例，按用途分类（流程/探索/优化/敏感性/构成），含生成脚本与 CATALOG | 合成/示例数据 |
| `MCM_B图表样张/` | 28 张图型与配色样张（含 29 页 PDF 图集、SVG、生成脚本与校验） | 合成数据，标注 SYNTHETIC DEMO |
| `MCM_B新结构样张/` | 12 张复合结构图（N01–N12，含 14 页 PDF 图集、检索说明与落地方法） | 合成数据与示意坐标 |
| `WorkFlowStyle/` | 论文工作流排版实验（STYLE_GUIDE、.sty、鱼骨/问题网格/圆角轮廓示例） | 排版样式，不含数据 |

使用规则：

1. 选定图型后，替换为真实数据、变量、单位、图例与来源，正式结果另存到 `Paper/Figure/`；LaTeX 优先引用矢量 PDF。
2. 各子目录的生成脚本与内部相对路径保持原样；移动整个目录不影响其内部链接。
3. 归档内容不参与模型结论，也不得在论文中把样图数值当作观测或拟合结果。
