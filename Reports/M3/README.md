## 思路主线

1. **承接 M2**：从项目第15年末的3个批次出发，继承实际导出的覆盖、有效储水、面积及末年补水申请。后评估第1年为项目第16年。
2. **承接 M1**：继续使用逐日水量平衡和年度植被更新，不恢复已删除的风损伤系数。
3. **添加灾害与趋势**：共同旱情改变降雨、需水、供水能力和风沙事件率；完整复合泊松过程表示风沙损伤；风、雨、事件率和旱年概率可随时间改变。
4. **资源落实**：先预留光伏清洗，再按月和年度上限配给生态补水。申请增加不等于实际交付同比增加。
5. **分别统计**：首次退化概率、当前低覆盖面积、可恢复的物理状态、50年受限平均首达时间（RMST）和覆盖代理积分。
6. **验证**：平稳二维链与物理蒙特卡洛对照，分开检查状态网格和冲击积分精度；同时检查接口、守恒及资源约束。

## 已完成成果

- 27组情景，每组50年。基准和平稳对照各6000条路径，其余各3000条。
- 基准后10年项目首次触发概率约77.47%，后30年约99.57%；50年6000条路径全部触发，但 Wilson 区间仍为约99.936%–100%。
- 后50年当前低覆盖期望面积约200.22 ha，而曾越界面积约299.45 ha；两者不同说明越界后仍可恢复。
- 基准覆盖积分约4761.89有效ha·年；相同背景趋势但无随机灾害时约7271.79。
- 28项联合测试通过；最细平稳网格的9个概率核验点均在MC区间内。状态网格和冲击积分加密的最大变化分别约0.0381、0.2024个百分点。

以上均为**条件压力测试**。灾害频率、幅度、未来趋势和诊断阈值未经本地标定，`formal_model_ready=false`。0.30K约为11.423%的覆盖代理，不能写成30%实际覆盖或已证实的防沙标准；RMST不能写成工程寿命。

## 复建报告

在仓库根目录执行：

```sh
python Reports/M3/build_tables.py
```

然后在`Reports/M3/`内运行两遍：

```sh
xelatex -interaction=nonstopmode -halt-on-error M3_writing_brief.tex
```

提表依赖现有Python环境中的Pandas；PDF采用XeLaTeX及Times New Roman字体。若模型输入或源码哈希变化，提表脚本会停止，应先确认数表版本，不能用旧结果配新模型。
